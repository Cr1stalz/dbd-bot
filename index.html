⚙️ Настройка Moobot

Custom Command + URL Fetch + Command argument 1

Command Moobot / StreamElements 
!dbd
Response → URL to fetch Full (plain) response 
https://dbd-bot-livid.vercel.app/api/dbd?steamid=
🔧 Собери URL в Moobot
https://dbd-bot-livid.vercel.app/api/dbd?steamid=
+
Command argument 1
⚠️ Важно: между = и блоком Command argument 1 пробела быть не должно.

📋 Как настроить Moobot

1
Создай новую Custom Command.
2
В поле Command укажи команду.
3
В строке Response выбери: URL fetch → Full (plain) response
4
В поле URL to fetch вставь URL из блока выше.
5
Сразу после = добавь блок Command argument 1. Пробела между ними быть не должно.
6
Сохрани команду.
