# Таймер «Решающий удар» (Decisive Strike)

Оверлей для OBS: показывает иконку перка и обратный отсчёт **60 секунд** — окно,
в течение которого работает DS после снятия с крюка.

**Главная фишка:** как только ты делаешь источник видимым — таймер запускается сам.

---

## Быстрый старт (2 минуты)

1. В OBS добавь источник **«Браузер»** (Browser / Источник → Браузер).
2. В поле **URL** укажи путь к файлу:

   ```
   file:///C:/Users/Cr1stalz/Documents/Проект по умолчанию/dbd-bot/overlay/index.html
   ```

   (кнопка «Обзор» рядом с полем URL подставит путь сама)

3. **Ширина / Высота:** `400 × 400` (или `500 × 500` — размер просто масштабирует оверлей).
4. Поставь две галочки в свойствах источника:

   - ☑ **Завершать работу источника, когда он не виден**
     *(Shutdown source when not visible)*
   - ☑ **Обновлять браузер, когда сцена становится активной**
     *(Refresh browser when scene becomes active)* — по желанию

5. Готово. **Скрыл источник → показал источник → таймер пошёл с 60.**

> Работает за счёт того, что OBS при скрытии источника полностью выгружает страницу,
> а при показе — загружает её заново. Загрузка страницы = старт таймера.

### Почему именно так, а не «по кнопке»

Никаких хоткеев, скриптов и плагинов. Переключаешь видимость источника — таймер стартует.
Удобно посадить источник на горячую клавишу OBS
*(Настройки → Горячие клавиши → «Показать источник "..."»)* или на макрос Stream Deck.

---

## Что показывает

| Состояние | Вид |
|---|---|
| `60…11` | иконка цветная, цифра белая |
| `10…6` | цифра желтеет, иконка «дышит» |
| `5…1` | всё красное, пульсация быстрее, писк на последних 3 секундах |
| `0` | иконка гаснет, надпись **ОКНО ЗАКРЫТО** |

---

## Настройки через URL

Параметры добавляются к адресу источника в OBS, например:

```
file:///C:/.../overlay/index.html?d=40&sound=1
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `d=60` | `60` | длительность в секундах (DS 1/2/3 уровня = 40/50/60) |
| `sound=1` | выкл | писк на старте, на последних 3 сек и в конце |
| `warn=10` | `10` | за сколько секунд начинать жёлтую пульсацию |
| `critical=5` | `5` | за сколько секунд включать красную пульсацию |
| `label=Текст` | `Решающий удар` | подпись под цифрой |
| `icon=URL` | — | своя картинка вместо встроенной |
| `bg=dark` | — | тёмная подложка (только для проверки в браузере) |
| `debug=1` | — | служебная строка внизу слева |

---

## Своя иконка

Рядом с `index.html` уже лежит **`icon.webp`** — настоящая иконка перка, оверлей берёт её
автоматически. Хочешь другую картинку — просто замени файл (квадратный, с прозрачным фоном)
или укажи путь: `?icon=file:///C:/icons/ds.png`.

Если картинки рядом нет, включится нарисованная встроенная иконка-заглушка.

## Продвинуто: запуск по видимости *другого* источника

Если сам оверлей у тебя всегда на экране, а запускать его надо по какому-то
другому источнику (например, по картинке «зацепили»), можно подписаться на
OBS WebSocket — таймер будет слушать видимость нужного источника.

1. В OBS: **Сервис → Настройки сервера WebSocket** → включить сервер,
   запомнить **пароль** и порт (по умолчанию `4455`).
2. В URL источника-оверлея добавь параметры:

```
file:///C:/.../overlay/index.html?mode=obs&scene=Игра&source=DS&pass=ТВОЙ_ПАРОЛЬ
```

| Параметр | Значение |
|---|---|
| `mode=obs` | включает режим ожидания |
| `scene=Игра` | имя сцены, где лежит источник-триггер |
| `source=DS` | имя источника-триггера |
| `pass=...` | пароль WebSocket (если включён) |
| `ws=ws://127.0.0.1:4455` | адрес сервера, если менял порт |
| `resetonhide=0` | не сбрасывать таймер, когда триггер скрыли |

В этом режиме оверлей при загрузке показывает «ОЖИДАНИЕ» и ждёт,
пока источник-триггер станет видимым.

## Если что-то не так

**Таймер не стартует при показе источника.**
Проверь галочку «Завершать работу источника, когда он не виден» и что источник
скрыт/показан именно в активной сцене.

**Таймер перезапускается каждый раз при переходе на сцену.**
Это галочка «Обновлять браузер, когда сцена становится активной». Выключи её,
если не нужно.

**Оверлей размытый / мелкий.**
Увеличь размер источника (например, `600 × 600`) — вся картинка масштабируется.

**Цифры не видно на светлом фоне.**
У текста есть тень, но лучше ставить оверлей на тёмную зону кадра
или включить `?bg=dark` для проверки.

**В игре DS перестаёт работать после починки всех генераторов** — таймер об этом
не знает, он считает только время. Если генераторы закрыты раньше — просто скрой источник.
