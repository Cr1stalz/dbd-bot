2

Настрой бота

Следуй инструкции для выбранного бота.

🤖 Настройка Moobot
  1. Открой панель управления Moobot.
  2. Перейди в раздел Commands → Custom Commands.
  3. Создай новую команду !dbd или используй другое название команды, которое тебе удобнее.
  4. В Response выбери URL fetch → Full (plain) response.
  5. В поле URL to fetch вставь адрес ниже.
  6. После знака steamid= добавь Command argument 1.
URL to fetch:
https://dbd-bot-livid.vercel.app/api/dbd?steamid=Command argument 1
⚠️ Важно: между steamid= и Command argument 1 не должно быть пробела.
💡 В результате должна получиться строка:

https://dbd-bot-livid.vercel.app/api/dbd?steamid=Command argument 1
👤 Зритель передаёт ссылку на Steam-профиль первым аргументом команды.
🖼️ Пример заполнения Moobot:
🟣 Настройка StreamElements
  1. Открой StreamElements.
  2. Перейди в Chat Bot → Commands.
  3. Создай новую Custom Command !dbd или используй другое название команды, которое тебе удобнее.
  4. В поле ответа вставь готовую строку ниже.
$(customapi https://dbd-bot-livid.vercel.app/api/dbd?steamid=$(queryescape $(1:)))
💡 Команда принимает ссылку на Steam-профиль первым аргументом.
3

Проверь команду

Пример команды с ссылкой

!dbd https://steamcommunity.com/id/cr1stalz_kz/
Зритель может указать любой Steam-профиль. Профиль не привязан к самой команде.
