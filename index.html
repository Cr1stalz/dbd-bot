DBD Bot

Полная инструкция по настройке статистики Dead by Daylight для Twitch через Moobot и StreamElements.

🚀 Начать настройку 💬 Команда !dbd

🚀 С чего начать

Для работы бота понадобятся Steam API Key, GitHub и Vercel.

🔑

Steam API

Получаем ключ Steam Web API, который используется для получения статистики игрока.

💻

GitHub

Храним код API в GitHub. При изменении кода Vercel автоматически обновляет сайт.

☁️

Vercel

Размещаем API в интернете и получаем ссылку, которую сможет использовать Twitch-бот.

🔑 Steam API Key

Ключ необходим для обращения к Steam Web API.

1

Открой Steam API

Перейди на страницу регистрации Steam Web API Key.

2

Войди в Steam

Авторизуйся под своим Steam аккаунтом.

3

Создай ключ

Укажи домен своего проекта и получи API Key.

4

Сохрани ключ

Не публикуй Steam API Key в открытом GitHub репозитории.

⚠️ Steam API Key является секретным ключом. Храни его только в переменных окружения Vercel.

☁️ Настройка Vercel

Размещаем API и подключаем Steam API Key.

1

Создай проект

Импортируй GitHub репозиторий с кодом DBD Bot.

2

Открой Environment Variables

В настройках проекта Vercel добавь переменную окружения.

Variable 
STEAM_API_KEY
3

Вставь Steam API Key

В поле Value вставь полученный Steam API Key.

4

Сделай Redeploy

После изменения переменных окружения необходимо заново задеплоить проект.

🤖 Moobot

Настройка команды !dbd в Moobot.

1

Открой Commands

Зайди в панель Moobot и открой раздел команд.

2

Создай команду

Название команды:

Command 
!dbd
3

Добавь API запрос

В ответ команды добавь URL API.

Moobot 
$(urlfetch https://dbd-bot-livid.vercel.app/api/dbd?steamid=76561199849381839)
4

Сохрани команду

После сохранения напиши !dbd в Twitch чате.

🟢 StreamElements

Аналогичная настройка команды через StreamElements.

1

Открой Chat Bot

Перейди в раздел Commands панели StreamElements.

2

Создай !dbd

Создай новую чат-команду с названием:

Command 
!dbd
3

Добавь запрос

Используй URL своего Vercel API в соответствии с синтаксисом StreamElements.

💡 Синтаксис команд может отличаться в зависимости от настроек и версии панели StreamElements.

❗ Ошибки

Частые проблемы при настройке.

Moobot показывает Data tag failure

Проверь URL API, доступность Vercel и правильность команды. API должен возвращать HTTP 200 с текстовым ответом.

Пишет «Игры скрыты»

Steam не отдаёт статистику Dead by Daylight. Проверь настройки приватности Steam и доступность Game Details.

Пишет «Время игры скрыто»

Steam не вернул информацию о времени игры Dead by Daylight.

Vercel возвращает ошибку

Проверь переменную STEAM_API_KEY в Environment Variables и после этого выполни Redeploy проекта.

❌ Если API полностью перестал отвечать, сначала открой ссылку API непосредственно в браузере. Так можно определить, проблема в Vercel/Steam или в Twitch-боте.

❓ FAQ

Ответы на основные вопросы.

Нужно ли пользователю вводить SteamID64?

Да, API может принимать SteamID64 или ссылку на Steam профиль.

Можно ли изменить ник бота?

Да. Ник Twitch-бота настраивается отдельно от самого API.

Можно ли добавить другие DBD показатели?

Да. Steam API возвращает большое количество статистических параметров Dead by Daylight.

Можно ли использовать API для нескольких каналов?

Да. Один API может использоваться несколькими Twitch-каналами при условии, что они обращаются к нему корректно.
